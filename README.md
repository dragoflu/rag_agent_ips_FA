# rag_agent_ips_FA

Прототип сервиса, который отвечает на вопросы по загруженным документам с помощью RAG, LLM и агентов.
Проект курса «Проект LLM 2026».

**Команда:** Флит Андрей

## Функционал

> В разработке. Раздел заполняется по мере готовности.

- [ ] Загрузка и автоматическая обработка документов (новые документы — без правки кода)
- [ ] Несколько вариантов RAG и агентов, выбираемых в настройках
- [ ] Выбор LLM в настройках
- [ ] Интерфейс: Telegram-бот или веб-интерфейс, приветственное сообщение и меню с описанием возможностей
- [ ] Оценка качества на открытом списке вопросов

## Структура

```
src/rag_ips/
  config.py      настройки из переменных окружения / .env
  ingest/        загрузка, парсинг и нарезка документов
  retrieval/     поиск: BM25, эмбеддинги, гибрид, реранкинг
  pipelines/     варианты RAG и агентов; общий интерфейс — pipelines/base.py
  llm/           клиенты LLM
  bot/           интерфейс пользователя
  eval/          метрики и оценка
tests/
data/            документы и индексы (в git не попадают)
```

## Запуск

Нужны Python 3.11+ и [Poetry](https://python-poetry.org/docs/#installation) 2.x.

```bash
poetry install
cp .env.example .env    # заполнить переменные, см. ниже
poetry run pre-commit install
poetry run pytest
```

## Переменные окружения

| переменная           | назначение                                                       |
| -------------------- | ---------------------------------------------------------------- |
| `TELEGRAM_BOT_TOKEN` | токен бота от @BotFather                                         |
| `LLM_BASE_URL`       | адрес OpenAI-совместимого API (по умолчанию OpenRouter)          |
| `LLM_API_KEY`        | ключ к этому API                                                 |
| `LLM_MODEL`          | модель по умолчанию                                              |
| `DATA_DIR`           | каталог с документами и индексами (по умолчанию `data`)          |
